# Storefront images

The supplied storefront images are kept in the project-level `images/` folder alongside `Landing Page.png`. The page references those files directly; filenames containing spaces are URL-encoded in `index.html` and `assets/js/main.js`.

If you replace an asset, keep its existing filename or update the corresponding `data-src` value in `index.html` and the matching hero slide in `assets/js/main.js`.
